Drag to rotate. Mouse wheel to zoom. The preview is only for orientation; the exported coordinates remain unchanged.

CNC note: STL is a 3D triangular mesh, while many CNC programs use DXF mainly for 2D profiles. This converter writes a true 3D DXF mesh using 3DFACE entities. Before machining, confirm that your CAM software accepts 3D DXF meshes. If it expects a 2D DXF outline, a section/profile extraction tool is more appropriate.
